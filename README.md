# Birthday Circle

> "Create a modern, colorful, and interactive web application called 'Birthday Circle' where users can share their birthdays and receive gifts.

> Core Features to build:

>  * User Authentication & Profiles:

>    * Signup/Login page.

>    * User profile setup with username, full name, avatar, bio, and birth date picker.

>  * Main Dashboard ('Today's Birthdays'):

>    * A feed listing all registered users who have their birthday today.

>    * Quick search bar to find users by name or username.

>  * Interactive User Profile Page:

>    * Profile display showing public info and received virtual gifts/cards.

>    * Wishlist Section: Option for the profile owner to add links to physical items they want.

>    * 'Send Gift' Button: A modal opening choices to send a virtual card with a custom message.

>  * Design & UI:

>    * Clean, vibrant, mobile-first responsive design using Tailwind CSS with subtle celebratory animations (like confetti)."
